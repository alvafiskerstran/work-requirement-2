# Work Requirement 2 – Flexbox Page with Form

A small single-page website about me, made as a mandatory assignment at Oslo Nye Fagskole.

## About the project
The page is built with semantic HTML and CSS. It includes:
- A navigation bar styled with Flexbox
- Sections about my background, work and interests
- A contact form with labels and HTML5 validation
- A footer centered with Flexbox

## How to view
Download or clone the repository and open `index.html` in a browser.
